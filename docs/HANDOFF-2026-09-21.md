## Things that are true and surprising

- **Outcomes must never carry hue.** The live HIT/MISS pair was 1.11:1 apart
  for ordinary colour vision and 1.09:1 under deuteranopia. No candidate pair
  in four design directions cleared 3:1 for a dichromat while clearing AA
  against the ground. Word plus shape, never colour.
- **The map restoration is not a revert.** All thirteen endpoints its layers
  fetched were deleted too, and the module tree reached into utils, services
  and types. maplibre-gl is pinned `^6` because v5 carried the only CRITICAL;
  v6 is ESM-only with **no default export**, so 46 files use namespace imports
  and `tsconfig.json` needs `geojson` in `types`. The stylesheet is bundled,
  never fetched from unpkg.
- **`npm pkg set` cannot set a dotted key.** It wrote `{"satellite":{"js":…}}`,
  which makes every npm command fail and causes
  `npm install --package-lock-only` to emit a 118-byte stub lockfile. A green
  typecheck against an empty lockfile means nothing.
- **Chrome headless is available** and is how to *see* a page rather than infer
  it. `.nw-reveal` sections never appear in a headless screenshot because the
  IntersectionObserver does not fire — check the DOM before concluding a
  section is missing.
